01

Prepare an isolated installed copy

Run from the repository root in PowerShell.

$RunRoot = Join-Path $env:TEMP ("wt-advisor-manual-" + [guid]::NewGuid().ToString("N"))
$WheelDir = Join-Path $RunRoot "wheel"
$VenvDir = Join-Path $RunRoot "venv"
$Database = Join-Path $RunRoot "acceptance.sqlite"
New-Item -ItemType Directory -Path $WheelDir | Out-Null
python -m pip wheel . --no-deps --no-build-isolation -w $WheelDir
python -m venv $VenvDir
$Python = Join-Path $VenvDir "Scripts\python.exe"
$Advisor = Join-Path $VenvDir "Scripts\wt-advisor.exe"
$Wheel = (Get-ChildItem "$WheelDir\war_thunder_advisor-*.whl").FullName
& $Python -m pip install $Wheel
Write-Host "Acceptance directory: $RunRoot"
Write-Host "Database: $Database"

PASS: wheel build and installation both exit successfully. Keep this PowerShell window open.
